# Lorenz Software community defaults

Shared community configuration for Lorenz Software's open-source projects.

The [funding configuration](.github/FUNDING.yml) points to
[Lorenz Software on GitHub Sponsors](https://github.com/sponsors/Lorenz-Software).
Repositories without their own funding configuration inherit this default.

Sponsorship helps maintain and improve our open-source PLC testing frameworks
and tools:

- [TC3 UnitTest](https://github.com/Lorenz-Software/Tc3UnitTest)
- [S7 UnitTest](https://github.com/Lorenz-Software/S7UnitTest)
- [PLCSIM.UnitTest](https://github.com/Lorenz-Software/PLCSIM.UnitTest)
